## Official Text Excerpt

> groupscope - Script command FDTD MODE DGTD CHARGE HEAT FEEM INTERCONNECT Changes the group scope. Script commands that add or modify simulation object use the groupscope property to know where to act within the object tree. For example, if you want to delete everything within a particular group, set the groupscope to that group (i.e. ::model::my_group). If you want to delete all objects in the simulation, set the group scope the root level (i.e. ::model). | Syntax | Description | ?groupscope; | returns the current group scope | groupscope("group_name"); | changes the group scope Example Create an analysis group with a Field and Index monitor. See Also Manipulating objects, delete, selectall, select
