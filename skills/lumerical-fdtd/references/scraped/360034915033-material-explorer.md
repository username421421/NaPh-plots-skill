## Official Text Excerpt

> Using the Material Explorer to view and adjust optical material models FDTD MODE DGTD FEEM The Material Explorer is used to check the material fits that will be used in the simulation. This is most important when using the Sampled data material type, although it can be used to check material properties for all material types. If the fit for a Sampled data material is not good enough, the Tolerance and Max coefficient properties and the wavelength range of the source can be edited in the Material Explorer.
