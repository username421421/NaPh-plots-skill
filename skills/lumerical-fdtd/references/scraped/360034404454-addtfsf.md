## Official Text Excerpt

> addtfsf - Script command FDTD MODE Adds a Total Field Scattered Field (TFSF) source to the simulation environment. | Syntax | Description | addtfsf; | Add a total field scattered field source to the simulation environment. This function does not return any data. |addtfsf(struct_data);| Adds a total field scattered field source and set its property using a struct containing "property" and value pairs. See the struct script command page for an example. This function does not return any data. Example The following script command will add a plane wave source in the FDTD simulation environment that will propagate in the negative z direction. The script will set the dimension (and position) of the source and will define the frequency range. See Also List of commands, set, addplane, addgaussian
