## Official Text Excerpt

> importsurface2 - Script command FDTD MODE DGTD CHARGE HEAT FEEM Imports surface data from script variables. This command only applies to import primitives. The function returns 1 if the data is successfully imported. Example script files showing how to use these functions can be found in the Online Help.
