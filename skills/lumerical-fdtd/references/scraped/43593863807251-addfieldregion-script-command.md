> addfieldregion - Script command FDTD Adds a field region object to the simulation environment. The field region object is used with lumopt, see the Knowledge Base article on Getting started with lumopt for more information. | Syntax | Description | addfieldregion; | Adds a field region object to the simulation environment. This function does not return any data. |addfieldregion(struct_data);| Adds a field region object and set its property using a struct containing "property" and value pairs.
