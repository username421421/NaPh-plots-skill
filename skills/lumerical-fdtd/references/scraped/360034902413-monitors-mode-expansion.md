## Official Text Excerpt

> Mode expansion monitor - Simulation object FDTD MODE Mode Expansion Monitors use overlap analysis to calculate the forward/backward propagating components of any mode of a waveguide or fiber at an arbitrary location in the simulation region. The Mode Expansion monitor facilitates the interoperability between FDTD and INTERCONNECT as it returns the S parameters, which can be imported into INTERCONNECT directly. For more information and tips on best practices to get the most accurate results from this monitor, see using the mode expansion monitor. Note that if performing parameter extraction using FDTD, using ports and the S-parameter sweep tool is preferable since the port objects can act as both sources and monitors and return S-parameters as a result.
