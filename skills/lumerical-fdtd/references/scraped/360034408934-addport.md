> addport (INTERCONNECT) - Script command INTERCONNECT Adds a port to a compound/script element (Note that this command does not apply for primitive elements). This topic addresses the addport command in INTERCONNECT - for information about the FDTD command, see addport (FDTD). | Syntax | Description | addport("element", "port", "type", "data", "position", "location"); | Adds a new port to the element with the specified properties. Returns the name of the port that is created. | Property || Default value | Type | Description | element | required || string | Name of the element to add a port to. | port | required || string | Name of the port to add. The named will be modified if there is already a port of the same name. | type | required || string | The type of port to add.
