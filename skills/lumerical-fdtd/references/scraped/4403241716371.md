> Topology optimization of a O-band/C-band wavelength de-multiplexer with 100nm feature size constraint Introduction With the 2019B-R2 release, we first introduced Topology Optimization which allows to automatically design high-performance devices. One of the challenges with Topology Optimization is the enforcement of minimum feature size constraints to ensure that the outcome is manufacturable, especially with optical lithography. On this page, the minimum feature size option will be demonstrated. It allows the user to specify a minimum feature size and the optimizer will automatically enforce this constraint, ensuring that the resulting design can be manufactured. The input and output waveguides are 500nm wide. The optimization takes approximately 800 iterations. During the binarization phase of this optimization, we enforce a minimum feature size of 100nm to ensure that the resulting device can be manufactured via optical lithography.
