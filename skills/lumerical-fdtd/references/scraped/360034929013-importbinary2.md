## Official Text Excerpt

> importbinary2 - Script command FDTD MODE DGTD CHARGE HEAT FEEM Import binary data (1s and 0s) over an entire volume from script variables. The object will be present wherever the binary data is 1 and not when it is 0. This command only applies to import primitives. The function returns 1 if the data is successfully imported. Example script files showing how to use these functions can be found in the Online Help.
