> Getting Started with Lumerical FDTD for Photonic Integrated Circuits - Part 3 This part of the tutorial will introduce how to use structure groups, analysis groups, and parameter sweeps to perform parametric analysis in Lumerical FDTD. A parametric waveguide bend structure group will be used to calculate the transmission through the waveguide bend as a function of bend radius.
