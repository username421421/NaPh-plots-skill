> Tips for creating structures with rounded corners FDTD MODE This section describes how to create objects with rounded corners. The example file here was created in FDTD, but these structures can be found in the component libraries of other products as well. Creating objects with rounded corners Method 1: Objects with rounded corners can be created with the polygon object. The simulation file usr_round_corners.fsp contains an n-sided equilateral shape with rounded corners created using the polygon primitive and then extruding. This object can also be accessed via the object library. By default, one corner of the object always points in the +X direction. The rotation tab of the structure group can be used to rotate the object. Method 2: Rounded objects can also be created using a combination of rectangles, spheres and extruded circles (tubes). Using the structure group script, the above all-rounded rectangular prism can be produced and easily modified.
