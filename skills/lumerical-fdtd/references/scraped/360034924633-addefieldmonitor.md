## Official Text Excerpt

> addefieldmonitor - Script command CHARGE Adds an electric field monitor to the simulation environment. This command requires the presence of a CHARGE solver region in the objects tree. | Syntax | Description | addefieldmonitor; | Adds an electric field monitor to the simulation environment. This function does not return any data. |addefieldmonitor(struct_data);| Adds an electric field monitor and set its property using a struct containing "property" and value pairs. See the struct script command page for an example. This function does not return any data. Example The following script commands will add a 2D y-normal electric field monitor to the simulation environment, set its dimension, enable saving the electrostatic potential, and save the data in a .mat file.
