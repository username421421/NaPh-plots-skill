## Official Text Excerpt

> Custom structure object - Simulation Object FDTD MODE Custom primitives are objects that are defined by equations describing the boundaries of the physical object. The custom primitive defaults to a rectangular region upon creation, and is shaped via the entry of one or more equations in the edit window. The custom object allows you to define the y position of the object as a function of the x position. The z position is obtained via extrusion or revolution of the y edge. (X,Y)=(0,0) corresponds to the center of the object.
