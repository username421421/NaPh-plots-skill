## Official Text Excerpt

> addgroup - Script command FDTD MODE DGTD CHARGE HEAT FEEM Adds a container group to the simulation environment. Container groups can be used to put multiple structures, monitors, and/or sources together in a single group in the objects tree. In Ansys Lumerical Multiphysics™, container groups are always children of the solver regions and cannot contain any structure. If multiple solver regions are present in the Ansys Lumerical Multiphysics objects tree, this command will add a container group to the solver region that is currently selected. | Syntax | Description | addgroup; | Adds a container group to the simulation environment. In Ansys Lumerical Multiphysics, the added container group is placed under the currently selected solver region. This function does not return any data. |addgroup(struct_data);| Adds a container group and set its property using a struct containing "property" and value pairs.
