> adddipole - Script command FDTD MODE Adds a dipole source to the simulation environment. In MODE the command requires an active varFDTD solver region in the objects tree. | Syntax | Description | adddipole; | Adds a dipole source to the simulation environment. This function does not return any data. |adddipole(struct_data);| Adds a dipole source and set its property using a struct containing "property" and value pairs. See the struct script command page for an example. This function does not return any data. Example The following script commands will add a dipole source to the FDTD simulation environment and set its position. See Also List of commands, set, addplane, addgaussian, addtfsf
