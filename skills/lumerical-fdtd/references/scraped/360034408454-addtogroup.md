> addtogroup - Script command FDTD MODE DGTD CHARGE HEAT FEEM Adds selected objects to a group. | Syntax | Description | addtogroup("group_name"); | Adds selected object(s) to a group. If a group with name "group_name" already exists, then the objects are added to the existing group. Otherwise, a group named "group_name" is created. "group_name" can be an absolute path, such as "::model::G1" Example Add a substrate in to a group "G2", and subsequently move the substrate back to "G1" See Also Manipulating objects, addgroup, addstructuregroup, addanalysisgroup, adduserprop, runsetup
