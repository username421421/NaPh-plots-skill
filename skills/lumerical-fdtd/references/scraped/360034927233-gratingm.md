## Official Text Excerpt

> gratingm - Script command FDTD MODE Returns a vector of the grating order numbers (i.e. zeroeth order, first order) corresponding to the data from the grating function. gratingn gives the order numbers for the first dimension of the data (2D and 3D). gratingm gives the order numbers for the 2nd dimension (3D only). See the grating function documentation for information on interpreting N, M, ux, uy for various monitor orientations. | Syntax | Description | out = gratingm( "monitorname",...); | Same arguments as grating function. Example This example calculates various grating quantities. See Also List of commands, grating, gratingn
