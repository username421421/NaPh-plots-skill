## Official Text Excerpt

> lumapi – SimObject.getParent – Python API Method Return the parent of the currently selected object in the Lumerical software. This command does not support objects where the parent was changed since object creation, for example, objects that had its parent changed via the addtogroup command. Syntax Parameters None Returns | Field | Type | Description | parentObj | SimObject | The parent simulation object for the currently selected simulation object.
