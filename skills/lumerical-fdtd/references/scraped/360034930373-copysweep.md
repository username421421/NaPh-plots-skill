> copysweep - Script command FDTD MODE DGTD CHARGE HEAT FEEM INTERCONNECT Copies a sweep/optimization/Monte Carlo analysis item to clipboard. | Syntax | Description | copysweep("name"); | Copies a sweep/optimization/Monte Carlo analysis item to clipboard.
