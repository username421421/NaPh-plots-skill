> getglobalmonitor - Script command FDTD MODE Sets global monitor properties. This command will return an error in analysis mode. | Syntax | Description | ?getglobalmonitor; | Returns a list of the global monitor properties | ?getglobalmonitor("property"); | Returns the value of the requested property. Example Set the global number of monitored frequency points to 11, then confirm value was set properly. See Also Manipulating objects, get, setglobalmonitor, setglobalsource, getglobalsource
