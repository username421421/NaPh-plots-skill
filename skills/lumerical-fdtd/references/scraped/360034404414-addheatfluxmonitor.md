> addheatfluxmonitor - Script command CHARGE HEAT Adds a heat flux monitor to the HEAT solver region. The monitor can only be added if the simulation environment already has a 'HEAT' solver present. | Syntax | Description | addheatfluxmonitor; | Adds a heat flux monitor to the simulation environment.
