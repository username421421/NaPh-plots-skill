## Official Text Excerpt

> getwizardinputs – Script command FDTD MODE DGTD CHARGE HEAT FEEM Obtains the structure of inputs to specific wizards. For more information on using the structure, see drivewizard. This command is only available on Linux. |Syntax|Description |getwizardinputs(“wizard_name”);| Obtains the structure of input for the wizard given by wizard_name. Currently, the only supported wizard_name is “layout geometry wizard”. Example See Also List of commands, drivewizard
