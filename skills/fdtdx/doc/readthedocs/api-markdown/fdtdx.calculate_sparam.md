Run the FDTD simulation and extract S-parameters from mode-overlap detectors.

Intended to be called with the outputs of <a href="fdtdx.setup_sparams_simulation.html#fdtdx.setup_sparams_simulation" class="reference internal" title="fdtdx.setup_sparams_simulation"><span class="pre"><code class="sourceCode python">setup_sparams_simulation()</code></span></a>. Each <a href="fdtdx.ModeOverlapDetector.html#fdtdx.ModeOverlapDetector" class="reference internal" title="fdtdx.objects.detectors.mode.ModeOverlapDetector"><span class="pre"><code class="sourceCode python">ModeOverlapDetector</code></span></a> in *objects* contributes one entry to the returned dictionary. Because a single simulation (with one active input port) measures the transmission to **all** output ports simultaneously, the dictionary keys are <span class="pre">`(detector_name,`</span>` `<span class="pre">`input_port_name)`</span> tuples so that results from multiple calls can be merged into a full S-matrix.

To simulate all input ports in one call (multiple simulations), use <a href="fdtdx.calculate_sparams.html#fdtdx.calculate_sparams" class="reference internal" title="fdtdx.calculate_sparams"><span class="pre"><code class="sourceCode python">calculate_sparams()</code></span></a>.
