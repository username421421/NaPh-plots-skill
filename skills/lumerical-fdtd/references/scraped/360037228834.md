> Lumerical scripting language - By category Lumerical's scripting language allows you to automate tasks and analysis such as manipulating simulation objects, launching simulations, and analyzing results. Script commands can be entered directly into the script prompt, run from a saved script file (.lsf), or used within some simulation objects.
