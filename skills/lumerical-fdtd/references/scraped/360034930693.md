## Official Text Excerpt

> farfield3d - Script command FDTD MODE Projects a given power or field profile monitor or a rectilinear dataset to the far field in a 3D simulation. The electric field intensity |E|2 is returned. | Syntax | Description | out = farfield3d("mname",f, na, nb, illumination, periodsa, periodsb, index, direction); | Projects a given power or field profile monitor to the far field. This returns an NxM matrix if 1 frequency point is projected, or a NxMxP matrix if more than 1 frequency point is projected, where N and M correspond to the resolution of the projection (na, and nb), and P corresponds to the number of frequency points projected. | out = farfield3d(dataset,f, na, nb, illumination, periodsa, periodsb, index, direction); | Projects a given rectilinear dataset to the far field. This returns an NxM matrix if 1 frequency point is projected, or a NxMxP matrix if more than 1 frequency point is projected, where N and M correspond to the resolution of the projection (na, and nb), and P corresponds to the number of frequency points projected. | Parameter || Default ...
